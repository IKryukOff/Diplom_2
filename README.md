# Diplom_2. API

Тестирование API сервиса [Stellar Burgers](https://stellarburgers.nomoreparties.site/)
1. Основа для написания автотестов — фреймворк pytest.
2. Перед запуском тестов установить зависимости — `pip install -r requirements.txt`.
3. Команда для запуска — `pytest tests --alluredir=allure_results`.
4. Для просмотра отчета — `allure serve allure_results`

## [Создание пользователя](tests/test_create_user.py)
* пользователя можно создать
* нельзя создать двух одинаковых пользователей
* чтобы создать пользователя, нужно передать в ручку все обязательные поля
* успешный запрос возвращает "success": true в теле ответа
* если одного из полей нет, запрос возвращает ошибку

## [Авторизация пользователя](tests/test_login_user.py)
* авторизация существующего пользователя проходит успешно
* авторизация с указанием неверного email/password возвращает ошибку некорректных данных

## [Обновление мнформации пользователя](tests/test_update_user.py)
* авторизованный пользователь может поменять данные (email/password/name)
* при обращении к эндпоинту без авторизации возвращается корректная ошибка (401) 

## [Создание заказа](tests/test_create_order.py)
* с авторизацией / без авторизации
* с ингредиентами / без ингредиентов
* с неверным хешем ингредиентов

## [Получение информации заказов пользователя](tests/test_get_orders.py)
* с авторизацией / без авторизации
